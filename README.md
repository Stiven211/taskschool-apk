# TaskSchool APK

Página de descarga del APK de TaskSchool con instrucciones de instalación para
Android.

**Sitio:** https://stiven211.github.io/taskschool-apk/

## Contenido

- `index.html`: página de descarga e instrucciones.
- `TaskSchool.apk`: instalador de la aplicación.

La app TaskSchool es un proyecto privado de gestión de tareas escolares.
